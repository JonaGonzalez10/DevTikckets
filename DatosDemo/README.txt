# Eventos Demo - Aplicación Fullstack

Dataset ficticio para una aplicación tipo Ticketmaster desarrollada con Spring Boot + Angular + MySQL.

- 20 eventos ficticios.
- Artistas/organizadores ficticios.
- Recintos y ciudades reales de México.
- 10 conciertos + 10 eventos de otras categorías.
- Las imágenes incluyen la leyenda EVENTO FICTICIO / DEMO.
- Los precios son datos de prueba y no representan precios reales.

Campos CSV:
id, nombre_evento, artista_organizador, categoria, recinto, ciudad, estado,
fecha, hora, precio_min, precio_max, imagen
